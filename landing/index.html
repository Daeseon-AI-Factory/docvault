DocVault

소규모 팀(~100 엔드포인트)을 위한 자체 호스팅 내부자 위협 이벤트 수집·조회 도구. 개인 포트폴리오 프로젝트입니다.

📘 설치 가이드 (한 / EN) GitHub Architecture Decisions Limitations

무엇을 하는가

osquery와 자체 제작 클립보드 에이전트가 사용자 PC에서 활동을 수집해 HTTPS로 서버에 전송합니다. 서버는 PostgreSQL에 저장하고 웹 UI에서 조회·검색하게 합니다. DB 트리거가 모든 로그에 SHA-256 해시 체인을 걸어 어플리케이션 레벨의 변조를 탐지합니다. 임계값 룰 10종으로 야간 접근, 대량 다운로드, 새 IP 같은 패턴을 점수화합니다.

  • 엔드포인트 이벤트 수집기 (파일 작업, 클립보드, USB, 메신저 접근 등)
  • DB 트리거 기반 해시 체인이 적용된 감사 로그
  • 임계값 룰 기반 이상 행위 점수화
  • htmx 기반 조회 UI
  • (옵션) AES envelope encryption 적용 파일 저장소

아닌 것

  • DRM이 아닙니다. 차단하지 않고 탐지만 합니다.
  • UEBA가 아닙니다. 머신러닝 없이 임계값 룰입니다.
  • 법적 증거 시스템이 아닙니다. DB 관리자 권한으로 해시 체인 우회가 가능합니다.
  • 프로덕션 보안 제품이 아닙니다. 인증·지원·SLA가 없는 개인 프로젝트입니다.

실행

컴퓨터를 잘 몰라도 복사·붙여넣기로 따라할 수 있는 설치 가이드 (한국어 / English)를 준비했습니다. 아래는 개발자용 요약입니다. 

make build
createdb docvault
./bin/docvault migrate
./bin/docvault seed
./bin/docvault serve    # http://localhost:8080

왜 만들었나

AI 어시스턴스를 사용해 12주 분량의 시스템을 설계·구현한 백엔드/보안 엔지니어링 포트폴리오 프로젝트입니다. 핵심 모듈(DB 트리거 해시 체인, 클립보드 에이전트 Win32 호출, envelope encryption)은 직접 이해하고 작성했습니다.

설계 결정의 솔직한 근거와 트레이드오프는 DECISIONS에, 알려진 결함과 미구현 영역은 LIMITATIONS에 명시되어 있습니다.
