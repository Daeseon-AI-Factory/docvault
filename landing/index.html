The Problem

Traditional DRM is Broken

Korean DRM solutions like Fasoo and Softcamp cost a fortune, slow down PCs, and frustrate employees.

Traditional DRM

  • Kernel-mode drivers crash PCs
  • 400MB+ RAM per endpoint
  • $50K+/year licensing
  • Blocks file access, breaks workflows
  • Complex deployment, agent conflicts
  • Employees find workarounds anyway

DocVault

  • User-mode only, zero OS hooks
  • ~50MB RAM, single binary
  • Open source, self-hosted
  • Never blocks — detect & alert
  • osquery + single Go binary
  • Employees don't know it exists
Features

Complete Endpoint Visibility

Every file operation, every clipboard copy, every USB insert — tracked in real time, without touching user workflows.

📄

File Operation Tracking

Create, modify, delete, rename, move — all file operations captured via osquery with SHA-256 hashes.

💬

Messenger Detection

KakaoTalk, Telegram, Slack, Discord, Teams — detect when messengers access sensitive documents.

📷

Clipboard Monitoring

Cross-platform agent (Windows + macOS) tracks every copy event with source app detection.

💾

USB & Network Copy

Detect files written to removable drives or network shares. Alert on sensitive file exfiltration.

🔎

Extension Disguise Detection

Catch users renaming .dwg to .jpg. SHA-256 hash comparison reveals content regardless of filename.

🔒

AES-256 File Vault

Streaming encryption with envelope key management. Files never fully buffered in memory.

📈

Real-time Dashboard

Server-Sent Events push alerts to the browser instantly. No refresh needed.

🎯

Hash-based File Tracking

Register critical files by SHA-256. Track them across all endpoints regardless of rename or move.

🔐

Two-Factor Authentication

TOTP (Google Authenticator) with 8 recovery codes. RFC 6238 compliant, zero dependencies.

Intelligence

User Behavior Analytics (UEBA)
