🪟 원클릭 설치파일

서버 주소와 인증키가 이미 들어 있습니다. 받아서 직원에게 보내면, 직원은 더블클릭만 하면 됩니다.

⬇ docvault-install.bat 다운로드

직원에게 보내는 법 (3단계)

  1. 위 버튼으로 docvault-install.bat 다운로드
  2. 직원에게 카톡 “파일 보내기” 또는 USB로 전달 (⚠️ 이메일은 .bat를 막아요 — 카톡/USB 권장)
  3. 아래 ②번 안내를 직원에게 보여주거나, 공개 설치 가이드 링크를 함께 보내기
💡 제일 확실한 방법: 직원이 컴퓨터에 익숙하지 않다면, 첫 설치는 원격(AnyDesk·팀뷰어)으로 직접 깔아주세요. 한 번만 깔면 끝입니다.

직원에게 그대로 보내는 문구

DocVault 설치 파일 보냅니다. 1. 받은 docvault-install.bat 파일을 바탕화면에 저장 2. 파일을 더블클릭 3. 경고창이 뜨면 [실행] → [예] → [추가 정보] → [실행] 순서로 누르기 4. 검은 창에 "설치 완료!"가 보이면 끝 5. 끝나면 완료 화면 사진을 저에게 보내주세요. Docker, WSL, PowerShell은 설치하거나 열 필요 없습니다. 막히면 그 화면을 사진으로 찍어서 보내주세요.
🚫 직원에게 시키지 말 것: Docker 설치, WSL 설치, PowerShell 명령 입력, 인증키 직접 입력, 이메일로 .bat 보내기. 직원은 파일 저장 → 더블클릭 → 버튼 누르기만 하면 됩니다.
