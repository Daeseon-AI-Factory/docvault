📥 에이전트 다운로드 & 설치 / Agent Download & Install

아래 파일을 대상 PC에 설치하면 활동 로그가 이 서버로 전송됩니다. (회사 소유 PC + 사용자 동의 하에 사용하세요.)
Install the agent on the target PC; it then reports activity to this server. Use only on company-owned PCs with user consent.

1) 다운로드 / Download

  • 🪟 Windows (64-bit) — dvclip.exe
  • 🍎 macOS (Apple Silicon / M1·M2·M3·M4)
  • 🍎 macOS (Intel)

2) Windows 설치 — PowerShell을 관리자 권한으로 열고 붙여넣기 / open PowerShell as Administrator and paste:

mkdir C:\DocVault -Force
move .\dvclip-windows-amd64.exe C:\DocVault\dvclip.exe
Unblock-File C:\DocVault\dvclip.exe
setx /M DOCVAULT_SERVER_URL "{{.ServerURL}}"
setx /M DOCVAULT_AGENT_PSK "{{.AgentPSK}}"
C:\DocVault\dvclip.exe install
net start DocVaultClipAgent

※ SmartScreen("Windows의 PC 보호") 경고가 뜨면 "추가 정보 → 실행"을 누르세요(미서명 앱이라 정상). If SmartScreen warns, click "More info → Run anyway".

제거 / Uninstall: net stop DocVaultClipAgent && C:\DocVault\dvclip.exe uninstall

2) macOS 설치(실행) — 터미널에서 / in Terminal:

xattr -dr com.apple.quarantine ~/Downloads/dvclip-macos-arm64
chmod +x ~/Downloads/dvclip-macos-arm64
DOCVAULT_SERVER_URL="{{.ServerURL}}" DOCVAULT_AGENT_PSK="{{.AgentPSK}}" ~/Downloads/dvclip-macos-arm64

※ "Apple이 확인할 수 없음" 경고는 미서명 앱이라 정상입니다. 위 첫 줄(xattr)이 차단을 풉니다. The "Apple could not verify" warning is expected (unsigned); the xattr line clears it.

⚠️ 위 명령에는 인증키(PSK)가 들어 있습니다 — 설치 담당자에게만 전달하세요.
These commands include the agent PSK — share only with trusted installers. 📘 자세한 설치 가이드 / Full setup guide
