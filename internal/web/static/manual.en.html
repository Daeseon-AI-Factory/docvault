DocVault user manual

This English version is suitable for portfolio demos. Use a separate demo database/server so real customer or friend data never mixes with sample data.

Dashboard

Shows total activity, risky events, AI briefing, and the Windows onboarding queue: unassigned PCs, capture-unverified PCs, offline PCs, and active install links.

Install Agent

Create one-time Windows install links for employees. The employee only sees a download button and Windows confirmation steps.

Agent Status

Verify heartbeat, session user, running mode, self-test result, and last real clipboard capture event.

Endpoint Events

Search file, USB, cloud upload, messenger, screenshot, and clipboard events collected from enrolled PCs.

Safe demo setup

  • Run the portfolio demo with docker-compose.demo.yml.
  • Use DOCVAULT_DEFAULT_LANG=en and DOCVAULT_DEMO_SEED=true.
  • Expose the demo through a separate domain or port from the production/friend instance.
  • Never import real production data into the demo database.
