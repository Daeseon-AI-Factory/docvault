🛡️ DocVault 모니터링 에이전트 설치 (Windows)

이 PC의 문서 활동(복사·USB 반출·외부 전송 등)을 회사 보안 서버로 보내는 작은 프로그램을 설치합니다. 약 5분이면 끝납니다.

⚠️ 회사 소유 PC에서, 회사 정책과 본인 동의 하에만 설치하세요. 개인 PC나 몰래 감시 용도로는 사용하지 않습니다.

설치 — 명령 한 번이면 끝

  1. PowerShell을 관리자 권한으로 열기
    시작 버튼 → powershell 입력 → Windows PowerShell 에서 마우스 우클릭 → 관리자 권한으로 실행 → "예" 클릭
  2. 아래 내용을 통째로 복사해 붙여넣고 Enter 
    mkdir C:\DocVault -Force
Invoke-WebRequest -Uri "https://docvault.daeseon.ai/download/dvclip-windows-amd64.exe" -OutFile "C:\DocVault\dvclip.exe"
Unblock-File C:\DocVault\dvclip.exe
setx /M DOCVAULT_SERVER_URL "https://docvault.daeseon.ai"
setx /M DOCVAULT_AGENT_PSK "관리자에게-받은-인증키"
C:\DocVault\dvclip.exe install
net start DocVaultClipAgent
    🔑 관리자에게-받은-인증키 부분은 관리자가 따로 알려준 값으로 반드시 바꿔주세요.
  3. 파란 경고창이 뜨면 "추가 정보 → 실행"
    "Windows의 PC를 보호했습니다" 창이 뜰 수 있습니다 → "추가 정보" 클릭 → "실행" 클릭.
    (정상입니다 — 외부 서명을 받지 않은 사내 프로그램이라 그렇습니다. 안전합니다.)

잘 설치됐는지 확인

마지막에 ...서비스를 시작했습니다 또는 service was started successfully 가 보이면 끝입니다. ✅

확인 명령: Get-Service DocVaultClipAgent → 상태가 Running 이면 정상 작동 중입니다.

설치 후엔 PC가 켜질 때 자동으로 시작되고, 꺼졌다 켜져도 알아서 다시 돕니다.

제거 (필요할 때)

관리자 PowerShell에서:

net stop DocVaultClipAgent
C:\DocVault\dvclip.exe uninstall

문제가 생기면

  • "이 시스템에서 스크립트를 실행할 수 없습니다" 오류 → 먼저 Set-ExecutionPolicy -Scope Process Bypass -Force 입력 후 다시 시도.
  • 다운로드 실패 → 인터넷 연결과 https://docvault.daeseon.ai 접속을 확인.
  • "net start" 오류 → 잠시 후 net start DocVaultClipAgent 다시 실행.
  • 그래도 안 되면 화면을 캡처해서 관리자에게 보내세요.
