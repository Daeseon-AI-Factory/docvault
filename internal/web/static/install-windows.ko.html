관리자가 보내준 파일 하나를 더블클릭만 하면 끝납니다. 1분이면 돼요. 화면에 뜨는 그대로 보여드릴 테니 천천히 따라오세요.

📌 딱 하나만 기억하세요
필요한 건 docvault-install.bat 파일 하나뿐입니다.
Docker·WSL 같은 건 절대 깔지 마세요. 그런 거 필요 없어요. (혹시 깔았다면 그냥 닫으면 됩니다.)
헷갈리면 멈추세요. 이 안내에 없는 창이 뜨면 아무거나 누르지 말고, 그 화면을 사진으로 찍어서 관리자에게 보내면 됩니다.

완료 화면 사진을 같이 보내면 관리자가 PC를 직원 이름에 바로 연결할 수 있어요.

🛠️ 전문가용 — 수동 설치 (위 방법이 안 될 때만)

PowerShell을 관리자 권한으로 열고(시작 → powershell 입력 → 우클릭 → 관리자 권한으로 실행), 관리자가 준 인증키를 넣어 아래를 붙여넣으세요:

mkdir C:\DocVault -Force
Invoke-WebRequest -Uri "https://docvault.daeseon.ai/download/dvclip-windows-amd64.exe" -OutFile "C:\DocVault\dvclip.exe"
Unblock-File C:\DocVault\dvclip.exe
setx /M DOCVAULT_SERVER_URL "https://docvault.daeseon.ai"
setx /M DOCVAULT_AGENT_PSK "관리자에게-받은-인증키"
C:\DocVault\dvclip.exe install
net start DocVaultClipAgent
🔑 관리자에게-받은-인증키 부분은 관리자가 알려준 값으로 바꾸세요. (원클릭 .bat에는 이미 들어 있어 안 바꿔도 됩니다.)

제거: net stop DocVaultClipAgent 후 C:\DocVault\dvclip.exe uninstall
