DocVault Windows install

For normal employees, installation is link-first: open the one-time link from your administrator, download docvault-install.bat, and run it. The page does not show the PSK, server URL, Docker, WSL, or PowerShell commands.

Employee steps

1. Open the install link sent by the administrator.
2. Click Download docvault-install.bat.
3. Save the file to the Desktop, then double-click it.
4. If Windows asks for confirmation, click Run, Yes, or More info -> Run anyway.
5. When the black window says installation is complete, close it.

Admin verification

  • Open Admin -> Install Agent to create one-time employee links.
  • Open Admin -> Agent Status to confirm the PC is reporting.
  • Ask the employee to copy any text with Ctrl+C; the PC should move to capture verified.
  • Unassigned, offline, problem, and capture-unverified PCs are visible on the dashboard.

Use DocVault only on company-owned devices with employee consent. Unsigned Windows installers may trigger SmartScreen until code signing is configured.
